# CodeAlpha Internship Projects

**Domain:** Full Stack Development

This repository contains two projects completed for the CodeAlpha internship.

## Task 1 — E-commerce Store (ShopSphere / NovaCart)

NovaCart is an online store where customers can browse products, search and filter the catalogue, add items to a cart, and go through the checkout flow. Customers can view their orders, while an admin can manage products and update order statuses.

**Built with:** React, Node.js, Express, MongoDB/Mongoose

Folder: `Task-1-Ecommerce/`

**Demo note:** The submitted demo uses sample data stored in memory. Changes made during a demo are temporary and are lost when the server restarts. The checkout page lets users select a payment method; it does not process real payments.

## Task 3 — Project Management Tool (NovaTask)

NovaTask helps a team organise projects and tasks. Users can create projects, assign tasks, move tasks across a Kanban board, add comments, and see updates from other open sessions.

**Built with:** React, Node.js, Express, MongoDB/Mongoose, Socket.io

Folder: `Task-3-Project-Management/`

**Live application:** https://novatask-f7f5.onrender.com/login

## Before running the projects

- Install Node.js and npm.
- Install the dependencies in each project's client and server folders.
- Add your own environment values in a local `.env` file.
- Do not commit `.env` files, passwords, database connection strings, or JWT secrets.
