# CodeAlpha Internship Tasks

**Domain:** Full Stack Development

This repository contains two projects completed as part of the CodeAlpha Full Stack Development Internship.

## Task 1 — E-commerce Store (ShopSphere / NovaCart)

A full-stack e-commerce application featuring:

- Product catalogue and product details
- Product search, filtering and sorting
- Shopping cart
- Customer authentication
- Checkout interface with multiple payment options
- Order history
- Admin dashboard and product management

**Technology:** React, Node.js, Express.js, MongoDB, Mongoose

Folder: `Task-1-Ecommerce/`

## Task 3 — Project Management Tool (NovaTask)

A project management application featuring:

- User authentication and role-based access
- Project and task management
- Kanban board with drag and drop
- Task comments and activity tracking
- Real-time updates using Socket.io
- Search, filters and analytics
- Project member management

**Technology:** React, Node.js, Express.js, MongoDB, Socket.io

Folder: `Task-3-Project-Management/`

Live application: https://novatask-f7f5.onrender.com/login

## Setup

Each project has its own frontend and backend. Refer to its individual README for installation and environment configuration.

Install dependencies separately inside each client and server folder using `npm install`.

Never commit `.env` files, passwords, API keys, database credentials or JWT secrets.

## Demonstration Notes

The ShopSphere demonstration uses seeded in-memory demo data. Changes are temporary and are not persisted to MongoDB.

NovaTask is deployed at the live application URL above.
